# Dr. Yogesh Patidar — Academic Portfolio

A light, interactive academic portfolio for Dr. Yogesh Patidar, Lecturer (Selection Grade-I), Electronics and Telecommunication Engineering, Government Polytechnic College, Mandsaur, Madhya Pradesh.

## Stack
- React + Vite
- Three.js / React Three Fiber for a live wireless-sensor-network visualization
- Framer Motion for interaction and transitions
- Responsive ivory, cobalt, coral, and ink design system

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Content note
Biography, education, career, books, NPTEL courses, and publication details are based on the CV supplied for this project. Please confirm all public contact details with Dr. Patidar before deployment. His mobile number is intentionally not published by default.
